音声暗記プレイヤー（GitHub Pages / Netlify 対応版）

【設置方法】
1. ZIP内のファイルをすべて同じフォルダに展開してください。
2. GitHub Pages のリポジトリ（今回の URL ではリポジトリ名 -2）に、ZIP内のファイルをすべてアップロードしてください。
3. GitHub Pages の公開URLを HTTPS で開いてください。
4. Chrome / Edge ではアドレスバー付近のインストール項目、またはブラウザメニューの「アプリをインストール」を確認してください。iPhone/iPad は Safari の共有メニューから「ホーム画面に追加」を使用します。

【今回の修正】
・/manifest.json や /sw.js のようなドメイン直下を指すパスを相対パスに変更しました。
・manifest の start_url / scope / アイコン参照を相対パスに変更しました。
・Service Worker のキャッシュ対象とオフライン時の index.html 参照を配置フォルダ基準に変更しました。
・Service Worker のキャッシュバージョンを更新しました。

【音声について】
標準ブラウザ音声はそのまま使用できます。Gemini AI 音声はソース内の API キーが空のため、このままでは利用できず、失敗時は標準ブラウザ音声へフォールバックします。公開リポジトリの HTML に秘密の API キーを直接書くのは避けてください。Gemini 音声を安全に使うには、API キーをサーバー側に置くバックエンドが必要です。

注意：このZIPを配置しただけで公開サイトが自動更新されるわけではありません。GitHub Pages / Netlify に再アップロードして公開してください。既にインストール済みの場合、ブラウザが古い Service Worker を保持していることがあります。サイトを再読み込みし、必要ならサイトデータを更新してください。
